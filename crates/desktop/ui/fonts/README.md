# Bundled terminal font

`JetBrainsMonoNLNerdFontMono-Regular.ttf` is JetBrains Mono NL Nerd Font Mono
from Nerd Fonts v3.5.1. It includes text, Powerline separators and the common
Nerd Font prompt glyphs used by zsh themes. The non-ligature monospaced variant
keeps the terminal on a stable character grid.

The font is bundled with the page so no network access or system font install
is needed. Settings may choose another installed family; this bundled family is
the default and remains the fallback for prompt glyphs.

See `OFL.txt` for the SIL Open Font License and attribution.
